1 Базовый синтаксис и типы данных

PHP — язык для серверной части сайта. Всё начинается с

  • Теги <?php ... ?>, инструкции заканчиваются ;.
  • Комментарии: //, #, /* */.
  • Скалярные типы: int, float, string, bool.
  • Сложные: array, object, callable, iterable.
  • Специальные: null, resource.
  • Строгость типов: declare(strict_types=1).
Пример strict_types
<?php
declare(strict_types=1);
function add(int $a, int $b): int { return $a + $b; }
add("5", 3); // TypeError: передана строка вместо int

2 Переменные и константы

Переменные начинаются с $ (например $name), константы задаются через define() или const. Область видимости — где объявил, там и живёт.

  • Переменные начинаются с $, чувствительны к регистру.
  • Константы: define() или const (для классов).
  • Предопределённые константы: PHP_VERSION, __DIR__, __FILE__, __LINE__.
  • Области видимости: глобальная, локальная и статическая (static внутри функции).

3 Операторы

Операторы — как посчитать и сравнить: + - * /, == и ===, && и ||, ?:, ??. Ключевое — строгое сравнение ===: оно не приводит типы.

  • Арифметические; сравнения: ==, ===, !=, !==, <=>; логические: &&, ||, !.
  • Тернарный оператор (?:), оператор объединения с null (??).
  • Инкремент/декремент, присваивание, строковый (.), побитовые.

4 Массивы

Массивы — списки и словари: $arr = ['a', 'b'] или ['ключ' => 'значение']. Почти всё в PHP работает через массивы — это его главная сила.

  • Индексированные и ассоциативные.
  • Создание: [] или array().
  • Важнейшие функции: count(), array_merge(), array_map(), array_filter(), array_reduce(), in_array(), array_keys(), array_values(), sort()/asort()/ksort().
  • Многомерные массивы.
  • Короткий синтаксис деструктуризации ([$a, $b] = $arr).

5 Строки

Строки — текст в кавычках. '' не подставляет переменные, "" подставляет. Основные функции: strlen, strpos, substr, str_replace, explode/implode.

  • Кавычки: '' (без интерполяции) и "" (с интерполяцией).
  • Heredoc / Nowdoc.
  • Основные функции: strlen(), strpos(), substr(), str_replace(), trim(), explode()/implode(), mb_* для многобайтовых (UTF-8).

6 Условные конструкции и циклы

if/else, switch, циклы for/while/foreach. Базовый поток выполнения — без них не работает ни один скрипт.

  • if, elseif, else, switch (сравнение через ==).
  • Циклы: for, while, do-while, foreach.
  • break, continue, return.

7 Функции

Функции — переиспользуемые блоки кода: function add($a, $b) { return $a + $b; }. Плюс замыкания и стрелочные функции — для собеса знать обязательно.

  • Определение: function name($param) { ... }.
  • Аргументы по умолчанию, передача по ссылке (&$param), типизация аргументов и возврата.
  • return — один выход, можно вернуть mixed.
  • Анонимные функции (замыкания), использование use для захвата переменных.
  • Стрелочные функции (fn() => ...) — короткий синтаксис.
Пример замыкания и стрелочной функции
<?php
$factor = 2;
$double = fn($x) => $x * $factor;      // стрелочная: автозахват $factor
$triple = function($x) use ($factor) { return $x * 3 * $factor; };
echo $double(4); // 8
echo $triple(4); // 24

8 ООП (классы и объекты)

ООП — программирование через объекты: класс, свойства, методы, наследование, интерфейсы, трейты. Основа всей современной PHP-разработки.

  • ООП: class, new, свойства (с модификаторами public, protected, private), методы.
  • Конструктор __construct(), деструктор __destruct().
  • Наследование (extends), переопределение методов, вызов родительского (parent::).
  • Интерфейсы (interface), реализация (implements), множественное наследование через trait.
  • Абстрактные классы и методы.
  • final (запрет наследования/переопределения).
  • Статические свойства и методы (static::, self::).
  • Магические методы: __get(), __set(), __call(), __callStatic(), __toString(), __invoke(), __clone(), __sleep()/__wakeup().
  • Клонирование объектов (clone).
  • Сравнение объектов (== и ===).

9 Пространства имён и автозагрузка

namespace — чтобы классы с одинаковыми именами не дрались, use — импорт. Автозагрузка через Composer (PSR-4) сама подтягивает классы по имени файла.

  • namespace — группировка классов.
  • use — импорт.
  • Автозагрузка через spl_autoload_register() или Composer (PSR-4).

10 Суперглобальные массивы

Суперглобальные — массивы, доступные из любого места: $_GET, $_POST, $_SESSION, $_COOKIE, $_SERVER, $_FILES. Это всё входные данные запроса.

  • Суперглобальные: $_GET, $_POST, $_REQUEST — данные запроса.
  • $_SESSION — данные сессии.
  • $_COOKIE — куки.
  • $_FILES — загруженные файлы.
  • $_SERVER — информация о сервере и окружении.
  • $_ENV — переменные окружения.
  • $GLOBALS — все глобальные переменные.

11 Работа с формами и файлами

Формы — как браузер шлёт данные на сервер: GET/POST, данные в $_POST, файлы в $_FILES. Вход всегда фильтруем — иначе XSS.

  • Отправка форм (метод GET/POST).
  • Валидация и фильтрация входных данных (filter_input(), htmlspecialchars()).
  • Загрузка файлов: проверка $_FILES, перемещение move_uploaded_file().
  • Обработка ошибок загрузки.

12 Сессии и куки

Сессии — данные пользователя на сервере (логин, корзина), куки — на клиенте. session_start() открывает работу с сессией.

  • Сессии: session_start(), чтение/запись $_SESSION, удаление (session_destroy()).
  • Куки: setcookie(), чтение через $_COOKIE, параметры: время, путь, domain, secure, httponly.

13 Работа с базами данных

База данных — хранилище данных сайта. PDO — единый способ подключения к MySQL и другим СУБД, prepared statements защищают от SQL-инъекций.

  • Два основных API: mysqli и PDO (рекомендуется).
  • Подключение, выполнение запросов, получение результатов.
  • Подготовленные запросы — защита от SQL-инъекций.
  • Транзакции (PDO: beginTransaction(), commit(), rollBack()).
  • Обработка ошибок (исключения PDO).
Пример безопасного CRUD-запроса через PDO
<?php
$pdo = new PDO('mysql:host=localhost;dbname=app', $user, $pass, [
    PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
    PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
]);
$stmt = $pdo->prepare('SELECT * FROM users WHERE email = ?');
$stmt->execute([$email]);           // параметры отдельно — нет инъекций
$user = $stmt->fetch();

$pdo->beginTransaction();
try {
    $pdo->exec('UPDATE accounts SET balance = balance - 100 WHERE id = 1');
    $pdo->exec('UPDATE accounts SET balance = balance + 100 WHERE id = 2');
    $pdo->commit();
} catch (Throwable $e) {
    $pdo->rollBack();
    throw $e;
}

14 Обработка ошибок и исключения

Обработка ошибок: try/catch ловит исключение и обрабатывает, throw — выбрасывает своё. error_reporting — что показывать, display_errors — показывать ли в браузер.

  • Уровни ошибок: E_ERROR, E_WARNING, E_NOTICE и др.
  • Настройка: error_reporting(), display_errors.
  • Исключения: try-catch-finally, throw, собственные классы исключений.
  • set_exception_handler(), set_error_handler().

15 Включение файлов

include/require вставляют один файл в другой. require упадёт с ошибкой, если файла нет, include — просто предупредит. require_once — защита от повторного включения.

  • include, require, include_once, require_once — разница: ошибка против предупреждения.

16 Современные возможности PHP 7/8 (обязательно знать!)

PHP 7 добавил строгие типы, ??, <=>. PHP 8 — match, enum, атрибуты, именованные аргументы, стрелочные функции. Отдельный большой блок вопросов на собесе.

  • PHP 7: скалярные типы, возвращаемые типы, оператор ??, <=>, группа use, анонимные классы.
  • PHP 8: именованные аргументы, атрибуты (аннотации), конструктор свойств (__construct(public $prop)), match, enum, тип mixed, static как тип возврата, never, throw как выражение, str_contains(), str_starts_with(), str_ends_with().
Пример PHP 8: match, enum, атрибут
<?php
#[Attribute]
class Route { public function __construct(public string $path) {} }

enum Status: string {
    case Draft = 'draft';
    case Published = 'published';
}

class Post {
    #[Route('/posts/{id}')]
    public function show(int $id): Status {
        $status = match ($id % 2) { 0 => Status::Draft, 1 => Status::Published };
        return $status;
    }
}

17 Безопасность (базовые практики)

Безопасность — защита сайта: XSS (экранируй вывод), CSRF (токены в формах), SQL-инъекции (prepared statements), пароли хешируй через password_hash().

  • SQL-инъекции → подготовленные запросы.
  • XSS → экранирование вывода (htmlspecialchars(), strip_tags()).
  • CSRF → токены в формах.
  • Валидация и фильтрация всех внешних данных.
  • Защита сессий (httponly, secure, регенерация ID).
  • Пароли: password_hash()/password_verify().
  • Ограничение загрузки файлов (тип, размер, имя).

18 Работа с датой и временем

Дата и время: date('Y-m-d H:i:s'), time() — метка, strtotime() — парсинг строк, класс DateTime — продвинутая работа. Про часовые пояса тоже спросят.

  • date(), time(), strtotime(), DateTime, DateTimeImmutable, DateInterval, DateTimeZone.
  • Форматирование, сравнение, разница.

19 Работа с JSON и сериализация

JSON — формат обмена данными: json_encode() превращает массив/объект в JSON, json_decode() — обратно. Сериализация — сохранение объектов в строку.

  • JSON: json_encode() / json_decode() (с опциями, обработка ошибок).
  • serialize() / unserialize() для хранения структуры.
  • Осторожно с unserialize (безопасность).

20 Регулярные выражения

Регулярные выражения — поиск по шаблону: preg_match, preg_replace, preg_split. Проверка email/телефона, вытаскивание данных из текста.

  • Функции PCRE: preg_match(), preg_match_all(), preg_replace(), preg_split().
  • Метасимволы, квантификаторы, модификаторы (i, u, s).

21 Работа с файловой системой

Файлы: fopen/fread/fwrite, file_get_contents/file_put_contents, mkdir, scandir, unlink. Чтение и запись файлов, работа с папками.

  • fopen(), fread(), fwrite(), fclose().
  • file_get_contents(), file_put_contents().
  • Директории: scandir(), mkdir(), rmdir(), unlink().

22 Отладка и тестирование

Отладка: var_dump, print_r, error_log, Xdebug с breakpoints. Тесты — PHPUnit. На собесе спросят, как ты дебажишь.

  • var_dump(), print_r(), var_export().
  • error_log() — запись в лог.
  • Xdebug (шаговая отладка, профилирование).
  • Юнит-тестирование: PHPUnit.

23 Composer и зависимости

Composer — менеджер пакетов PHP: composer.json, секции require и require-dev, автозагрузка PSR-4. Без него не живёт ни один современный проект.

  • composer.json, require, require-dev.
  • Автозагрузка (PSR-4).
  • Обновление зависимостей.

24 Паттерны проектирования (хотя бы поверхностно)

Паттерны — готовые решения типовых задач: Singleton, Factory, Dependency Injection, Repository, Observer. Хотя бы назвать и объяснить, зачем.

  • MVC (Model-View-Controller) — основа большинства фреймворков.
  • Singleton, Factory, Dependency Injection, Repository, Observer.
  • Понимание принципов SOLID.

25 Фреймворки (базовое знакомство)

Фреймворк — готовый каркас сайта: Laravel, Symfony, Yii. Маршруты, ORM, шаблоны, авторизация из коробки. Laravel сейчас самый популярный.

  • Laravel, Symfony, Yii, CodeIgniter.
  • Структура, ORM (Eloquent, Doctrine), маршрутизация, шаблонизаторы (Blade, Twig).

26 REST API

REST API — отдача данных по HTTP: методы GET/POST/PUT/DELETE, статус-коды (200, 404, 500), обмен в JSON. Авторизация через JWT или OAuth.

  • Методы HTTP: GET, POST, PUT, DELETE.
  • Форматы ответов: JSON, XML.
  • Авторизация: JWT, OAuth.
  • Статус-коды.

27 Кэширование и очереди

Кэш — быстрое хранение тяжёлых данных (Redis, Memcached). Очереди — отложенные задачи (RabbitMQ, Redis). Ускоряют сайт и разгружают сервер.

  • Кэширование: Redis, Memcached, APC.
  • Очереди: RabbitMQ, Redis (pub/sub), очереди в БД.

28 Работа с электронной почтой

Почта: mail(), PHPMailer, SMTP-протокол. HTML-письма, вложения, отправка через внешние сервисы, чтобы не уходить в спам.

  • mail(), PHPMailer, SwiftMailer (отправка через SMTP).

29 Обработка изображений

Изображения: GD и Imagick — ресайз, обрезка, водяные знаки, конвертация форматов. Всё для загрузки аватарок и фоток.

  • GD, Imagick (изменение размера, обрезка, наложение).

30 Практические советы для собеседования

Советы: повтори типы и сравнения, покажи понимание ООП, расскажи про безопасность, не ври в опыте и решай задачи вслух.

  • Умей написать простой CRUD с PDO.
  • Знай isset(), empty(), is_null() и их отличия.
  • Разница между include и require, echo и print.
  • Объясни, как работает сессия (куки + файл/база).
  • Примеры использования трейтов, интерфейсов, абстрактных классов.
  • Что такое переменные переменные ($$var).
  • Понимай замыкания и передачу по ссылке.
  • Будь готов к вопросам «что выведет код».
Совет: проговаривай определения вслух, а потом напиши мини-CRUD с PDO без подсказок — так тема закрепится надёжнее.
